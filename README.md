# Student House Cleaning System

student-house-cleaning/
  frontend/   (HTML, Tailwind, JavaScript)
  backend/    (Node.js, Express, MongoDB)

## Run
1. Install Node.js and MongoDB (or use a free MongoDB Atlas link).
2. cd backend
3. copy .env.example to .env and fill in the values
4. npm install
5. npm run dev
6. Open http://localhost:5000/login.html
   First: POST /api/auth/register {"username":"admin","password":"123456"}  (first user = admin)
